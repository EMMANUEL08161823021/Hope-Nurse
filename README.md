# Hope Nurse Exam — Minimal README

## Overview
A simple PHP + MySQL exam system with admin and student areas. Admins create exams; students can take exams and view results (when released).

## Tech stack
- PHP 8+ (tested with 8.0+)
- MySQL / MariaDB
- PDO for DB abstraction
- Bootstrap 5 for UI
- (optional) XAMPP / MAMP for local dev
